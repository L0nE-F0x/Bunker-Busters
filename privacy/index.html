Privacy

What the game keeps

Bunker Busters has no accounts, ads, analytics, tracking or cookies. This page lists everything it stores and every request it makes.

Last changed 31 October 2026

On your device

  • Your saved game and your settings (graphics, sound, controls) are kept in your browser's local storage for this site, or in the desktop app's own storage. They never leave your device. Clearing the site's data in your browser, or uninstalling the app, deletes them. On Linux the app keeps them in ~/.local/share/dev.bunkerbusters.game.
  • The same storage holds a few small notes the game makes for itself: which graphics mode works on your device, whether you've installed it on your phone, and, on the home page, the latest release's details for an hour so it doesn't ask GitHub on every visit.
  • Offline play. After the browser version first loads, it saves all of the game's files (under 100 MB) in your browser's cache, so it starts faster and plays with no connection, and asks the browser to keep them. Clearing the site's data removes them.

Over the network

  • Netlify hosts this site and the browser version. Like any web host it keeps standard server logs (your IP address, the address you asked for, your browser's name) to run and protect the service. The game adds no analytics on top of them. See Netlify's privacy policy.
  • GitHub. The download section of the home page asks GitHub's API for the latest release, to show its version and file sizes. The downloads themselves come from GitHub Releases. Both are covered by GitHub's privacy statement.
  • The desktop app asks GitHub Releases whether there's a newer version when you reach the title screen. It sends nothing about you or your game. It only downloads an update when you choose Update & restart, and it checks the update's signature before installing it.
  • The trailer on the press kit page, once there is one, comes from YouTube. Nothing loads from YouTube until you press play; from then on Google's privacy policy applies.
  • Everything else, including fonts, models and voices, comes from this site. No page loads scripts, fonts or embeds from anyone else.

Questions

Open an issue on the game's GitHub page. If any of this changes, this page will change with it and get a new date.
